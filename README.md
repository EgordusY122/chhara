### Тема: «Автоматизация бизнес-процессов управления персоналом на базе информационной системы»
## Выполнил: Алексеев Егор, Иванов Михаил

# 1. Введение
*Актуальность:* Дефицит кадров и ручная обработка резюме затягивают подбор. Автоматизация HR сокращает рутину и ускоряет найм.
*Цель:* Создание ИС для автоматизации подбора, онбординга, кадрового учета и аналитики.
*Задачи:* Анализ процессов, проектирование БД, разработка модулей, тестирование и внедрение.

# 2. Обоснование выбора темы
Готовые ERP/CRM дороги или громоздки. Разработка своей ИС сократит время найма (Time-to-Hire) и упростит адаптацию сотрудников.

# 3. Объект и предмет исследования
Объект: Бизнес-процессы HR-департамента (найм, адаптация, учет).
Предмет: Автоматизация этих процессов с помощью ИС.

# 4. Анализ бизнес-процессов управления персоналом
*Процессы:* Публикация вакансий, проведение интервью, офферы, онбординг, учет кадров, HR-аналитика.
*Требования:* Исключение дублирования данных, автоуведомления, разграничение прав доступа.

# 5. Цели и задачи проекта
Цель: Повышение эффективности работы кадровой службы.
Задачи ИС: Проектирование БД, создание UI, реализация воронки найма, настройка уведомлений и отчетов.

# 6. Техническое описание системы
Архитектура: Веб-приложение (Backend: Python / FastAPI; Frontend: React; БД: PostgreSQL).
Модули: Вакансии, Собеседования, Адаптация, Учет сотрудников, Аналитика.

# 7. Бизнес-процессы и их автоматизация
*BPMN-сценарии:* Отклик, интервью, прием в штат, онбординг, отчётность.
*Автоматика:* Автосмена статусов, генерация чек-листов адаптации, Email/PUSH-уведомления.

# 8. Описание сущностей
1. Вакансия (Vacancy): ID, Title, Department, Salary_Range, Status.
2. Кандидат (Candidate): ID, Full_Name, Contacts, Resume_URL, Current_Stage.
3. Собеседование (Interview): ID, Candidate_ID, Vacancy_ID, Interviewer_ID, Date_Time, Feedback, Status.
4. Сотрудник (Employee): ID, Full_Name, Position, Department, Hire_Date, Status.
5. Задача адаптации (OnboardingTask): ID, Employee_ID, Task_Name, Due_Date, Mentor_ID, Status.

# 9. Ожидаемые результаты
- Сокращение времени найма на 30%.
- Успешное прохождение онбординга 90% новичков.
- Снижение рутинной нагрузки на HR-менеджеров.

# 10. Заключение
ИС повышает прозрачность кадровой работы, снижает операционные риски и готовит платформу для масштабирования компании.
